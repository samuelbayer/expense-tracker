## Expense Tracker

Expense tracker app with login, categories and a monthly dashboard.

**[Live demo →](https://expense-tracker-xi-orpin.vercel.app/)**

## Status

Under construction: 0 of 6 phase

## Stack

Next.js, TypeScript, Tailwind, Supabase, React Hook Form + Zod, Vitest.

## Running Locally

Create a .env.local file with your Supabase URL and key (see .env.example)

```bash
pnpm install
pnpm dev     # start the dev server

```
